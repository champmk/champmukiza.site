Projects and recognition

ModForge

Solo project · 2026 · on npm

ModForge is a deterministic engine for migrating Minecraft mods across versions. It never guesses a rename: every result is joined through the real mappings and checked against the actual game jar, then graded EXACT, CANDIDATE, or UNRESOLVED. It’s published on npm, and it ships an MCP server so AI agents can ask for verified mappings instead of making them up.

Repository · npm · Deltas

fabric-te

Solo project · 2026 · Rust

Training jobs miss their deadline on a cluster that still has free GPUs, because the cables those jobs need are already full. I built a simulator of that network, and two controllers: one that packs free chips the obvious way, and one that looks at leftover bandwidth first. The obvious one admits jobs that then miss. The careful one refuses.
